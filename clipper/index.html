Multimodal Search

Search using text, images, or both. Clipper intelligently combines your queries to find the most relevant results.

Búsqueda Multimodal

Busca usando texto, imágenes, o ambos. Clipper combina inteligentemente tus consultas para encontrar los resultados más relevantes.

psychology

Semantic Understanding

Powered by the SigLIP-2 model, Clipper understands the *meaning* and *context* of your search, not just keywords.

Comprensión Semántica

Potenciado por el modelo SigLIP-2, Clipper entiende el *significado* y *contexto* de tu búsqueda, no solo palabras clave.

bolt

High-Speed Vector Search

Built on BeaverDB, Clipper delivers search results from millions of images in milliseconds, enabling real-time visual search.

Búsqueda Vectorial de Alta Velocidad

Construido sobre BeaverDB, Clipper entrega resultados de millones de imágenes en milisegundos, permitiendo una búsqueda visual en tiempo real.

merge_type

Advanced Fused Search

Optionally fuse text and image queries into a single, averaged vector for a new class of powerful semantic search.

Búsqueda Fusionada Avanzada

Opcionalmente fusiona consultas de texto e imagen en un único vector promediado para una nueva clase de búsqueda semántica potente.

sort

Advanced Re-Ranking

When searching by multiple inputs, Clipper uses Reciprocal Rank Fusion (RRF) to intelligently merge and rank all result lists.

Re-clasificación Avanzada

Al buscar con múltiples entradas, Clipper usa Reciprocal Rank Fusion (RRF) para fusionar y clasificar inteligentemente todas las listas de resultados.

dns

Backend Autogestionado

La aplicación Streamlit gestiona automáticamente sus propios servicios de backend (SigLIP & Beaver), simplificando la configuración y el despliegue.

The Technology Behind Clipper

Best-in-class open-source components.

La Tecnología Detrás de Clipper

Componentes de código abierto de primera clase.

auto_awesome

SigLIP-2 Embeddings

Embeddings SigLIP-2

We use Google's state-of-the-art SigLIP-2 model to convert all images and text queries into rich vector embeddings.

Usamos el modelo de última generación SigLIP-2 de Google para convertir todas las imágenes y consultas de texto en ricos embeddings vectoriales.

storage

BeaverDB Vector Store

Base de Vectores BeaverDB

BeaverDB is a high-performance, disk-based vector database that stores and searches millions of embeddings with incredible speed.

BeaverDB es una base de datos vectorial de alto rendimiento basada en disco que almacena y busca millones de embeddings con una velocidad increíble.

desktop_windows

Managed by Streamlit

Gestionado por Streamlit

Toda la experiencia está envuelta en una aplicación Streamlit simple e interactiva. Incluso gestiona el inicio y la detención de los servidores de backend de embedding y base de datos por ti.

Frequently Asked Questions

Have questions? We have answers.

Preguntas Frecuentes

¿Tienes preguntas? Tenemos respuestas.

Security is our top priority. Clipper is designed to run on your local computer or within your enterprise network (on-premise). In these scenarios, your data never leaves your firewall.

La seguridad es nuestra máxima prioridad. Clipper está diseñado para ejecutarse en tu computadora local o dentro de tu red empresarial (on-premise). En estos escenarios, tus datos nunca salen de tu firewall.

This version of Clipper is optimized for SigLIP-2 for embeddings and BeaverDB for search. These were chosen for their top-tier performance and efficiency. Future versions may support other models.

Esta versión de Clipper está optimizada para SigLIP-2 para embeddings y BeaverDB para la búsqueda. Fueron elegidos por su rendimiento y eficiencia de primer nivel. Versiones futuras podrían soportar otros modelos.

Clipper works with all standard image formats, including, but not limited to, JPG, PNG, WebP, GIF, and BMP. It indexes the *visual content* of the images, allowing you to search by concepts, objects, and style.

Clipper funciona con todos los formatos de imagen estándar, incluyendo, pero no limitado a, JPG, PNG, WebP, GIF y BMP. Indexa el *contenido visual* de las imágenes, permitiéndote buscar por conceptos, objetos y estilo.
