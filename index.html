Flagship

aegis.
A workplace for teams of coding agents.

aegis brings the coding agents you already pay for (Claude Code, Codex, OpenCode, Cursor) into one browser workplace. Start with one agent. Grow to agents that plan, wait for each other and hand work along, while you decide.

aegis.syalia.com arrow_outward GitHub arrow_outward
Your agents, your accounts

aegis calls no model and holds no key. Every agent is a session you can watch and talk to.

Grows with the work

One agent in a tab, several projects at once, then queues and workflows where agents hand tasks to each other.

Geocoder

Offline geocoding for Cuba

Turns Cuban addresses like “Calle 23 e/ L y M” into a point on the map, with no internet. Reverse lookup, routes, visit order and whole spreadsheets at once, built on OpenStreetMap.
